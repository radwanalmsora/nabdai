# Nabd AI

منصة مفتوحة المصدر لبناء وكلاء ذكاء اصطناعي عرب مع دعم العربية والخصوصية والتشغيل المحلي.

Nabd AI مساحة عمل عربية لإنشاء وكلاء أذكياء، ربطهم بقاعدة معرفة، وتجربة المحادثة معهم من واجهة RTL قابلة للتوسع.

## النسخة الأولية

تتضمن لوحة تحكم عربية، قائمة وكلاء مع البحث، تدفق إنشاء وكيل، محادثة تجريبية، ورفع ملفات PDF وWord كواجهة أولية لقاعدة المعرفة.

## التشغيل

```bash
pnpm install
pnpm dev
```

## التقنية

React, TypeScript, Vite, Tailwind CSS, Express, tRPC, Drizzle ORM.
